# Psicología Maricielo Encarnación - Sitio Web Profesional

Una página web moderna y profesional para la psicóloga Maricielo Encarnación, especializada en psicología educativa.

## Características

### 🎨 Diseño Visual
- **Hero Section** con imagen de fondo completa y overlay oscuro
- **Glassmorphism** en tarjetas y secciones
- **Animaciones suaves** al hacer scroll
- **Diseño responsive** para celulares, tablets y computadoras
- **Paleta de colores** profesional y confiable

### 📱 Estructura del Sitio
- **Header** moderno con navegación transparente que cambia al hacer scroll
- **Hero Section** con llamada a la acción clara
- **Sección Sobre Mí** con información profesional
- **Servicios** con 8 especialidades diferentes
- **Formulario de contacto** moderno y funcional
- **Botón flotante de WhatsApp** integrado

### 🛠️ Tecnologías Utilizadas
- **HTML5** semántico y accesible
- **CSS3** con animaciones modernas y glassmorphism
- **JavaScript** vanilla para interactividad
- **Font Awesome** para íconos
- **Google Fonts** (Playfair Display + Inter)

## 🚀 Funcionalidades

### Interactividad
- **Menú de navegación** responsive con animación hamburguesa

- **Animaciones al scroll** con Intersection Observer
- **Efecto parallax** en el hero section
- **Formulario de contacto** con validación
- **Notificaciones** elegantes para retroalimentación

### Diseño Responsive
- **Mobile-first** approach
- **Breakpoints** para tablets y celulares

- **Optimización** de imágenes y rendimiento
